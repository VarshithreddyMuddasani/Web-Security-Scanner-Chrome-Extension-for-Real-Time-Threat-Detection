🔐 Web Security Scanner Chrome Extension

A lightweight Chrome extension that scans websites in real time to detect basic security issues and provide risk-based analysis.

🚀 Features
Detects HTTPS / insecure HTTP
Identifies missing CSP
Finds external scripts & iframes
Shows risk level (Low / Medium / High)
Color-coded results

🛠️ Technologies Used
JavaScript
HTML
CSS
Chrome Extension API (Manifest v3)
