🔐 Web Security Scanner Chrome Extension

A lightweight Chrome extension that scans websites in real time to detect basic security issues and provide risk-based analysis.

🚀 Features
    
  - Detects HTTPS / insecure HTTP
- Identifies missing CSP
- Finds external scripts & iframes
- Shows risk level (Low / Medium / High)
- Color-coded results

🛠️ Technologies Used
- JavaScript
- HTML
- CSS
- Chrome Extension API (Manifest v3)

🧠 How It Works

The extension injects a content script into the active webpage and performs:

- HTTPS validation
- CSP detection
- External script analysis
- Iframe detection

A risk score is calculated and displayed with color-coded indicators.

🎯 Project Objective

To improve user awareness about web security by providing a simple, fast, and real-time browser-based analysis tool.
